# Spartan Company — Site vitrine

Site statique (HTML / CSS / JS) de Spartan Company, déménagement professionnel à Paris & Île-de-France.

Hébergé sur GitHub Pages — https://spartancompany.fr

## Structure

- `index.html` — page d'accueil
- `mentions-legales.html` — mentions légales
- `style.css`, `script.js` — styles et interactions
- `assets/images/` — visuels du site
- `assets/favicons/` — icônes navigateur / mobile
- `CNAME`, `robots.txt`, `sitemap.xml`, `site.webmanifest` — config domaine, SEO, PWA

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000
